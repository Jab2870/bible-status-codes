# HTTP Bible

Bible verses for HTTP status code.

## Website

<https://jab2870.github.io/bible-status-codes/>

## About

This project maps HTTP status codes to Bible verses. The verses are from the **Berean Standard Bible (BSB)**, a free public domain translation.

See [bsb-translation](https://bereanbible.com/) for more about the BSB translation.

## Local Development

```bash
cd hugo
hugo server -D
```

## Build

```bash
cd hugo
hugo --minify
```
