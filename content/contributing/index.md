# Contributing

The source code is available on [GitHub](https://github.com/Jab2870/bible-status-codes) or [Codeberg](https://codeberg.org/jab2870/bible-status-codes).

If you're comfortable opening a pull request, please feel free to do so!

If not, you can [create an issue](https://github.com/Jab2870/bible-status-codes/issues/new?template=verse-suggestion.yml) on GitHub:

1. Go to the GitHub issues page
2. Click "New issue"
3. Select "Submit a verse suggestion"
4. Fill in the form with:
   - The HTTP status code
   - The Bible verse (please use the BSB translation)
   - Any explanation for why this verse fits the status code
