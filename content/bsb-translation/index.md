# The Berean Standard Bible (BSB)

I chose the **Berean Standard Bible (BSB)** translation for this project for a
couple of reasons. But mostly, I support want to support the project. I think
bibles should be public domain, and BSB have done that.


## Learn More

Visit the official [Berean Bible website](https://berean.bible/) to learn more
about the BSB, download free copies, or explore their other translation tiers.
